# PRESSROOM

An independent artist's printing desk. Paper #f4efdf, workbench #e8e6df, graphite #1e211e, vermilion #ee492e, ultramarine #1749e8. Editorial type, precise rules, modern native controls. Main object is an editable poster. Five distinct compositions, no stock images. UI text >= 12px, inputs >= 16px, touch actions >= 44px. Focus uses a 3px blue outline. Mobile stack with sticky section tabs, no blocking bottom overlay. Print movement is short and reduced-motion aware. All exported text becomes paths. See README for reference links.
